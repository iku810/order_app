# 画面仕様書

画面仕様を定義する
画面遷移には[go_router](https://pub.dev/packages/go_router)を利用する

## 画面遷移図

```mermaid
graph TD
    A[ログイン画面]
    B[テーブル一覧画面]
    C[ログアウト画面]
    D[チェックイン画面]
    E[注文履歴画面]
    F[注文画面]
    G[会計画面]

    A -->|ログイン成功| B
    B -->|設定ボタン| C
    C -->|ログアウト成功| A
    B -->|テーブル選択 チェックアウト| D
    D -->|チェックイン成功| B
    B -->|テーブル選択 チェックイン中| E
    E -->|追加ボタン| F
    E -->|会計ボタン| G
    F -->|注文ボタン成功| B
    G -->|チェックアウト成功| B
```
## 共通
### ローディング / エラー / 空データの表示

- ローディング: 処理中（API 呼び出し中）は画面中央にプログレスインジケータを表示する。
- 空データ: リストが空の場合は説明テキストとアクション（例: 再読み込みボタン）を表示する。
- エラー: エラー時はダイアログでエラーを表示し、必要に応じてリトライを提供する。

### ナビゲーション期待動作

- バック操作: 画面の戻る操作は直前の画面へ戻る（ログイン直後はアプリ終了としない）

## ログイン画面
- [flutter_appauth](https://pub.dev/packages/flutter_appauth)を利用する

### 表示項目

| 項目名　       | 表示形式 | 　説明                                                                                                 |
| -------------- | -------- | ------------------------------------------------------------------------------------------------------ |
| ヘッダー       | ヘッダー | タイトルを表示                                                                                         |
| ログインボタン | ボタン   | 押下時に認可ページを外部ブラウザで開く |

### 画面状態モデル

1. **未ログイン** – このログイン画面を表示。大きなログインボタンのみ。
2. **認可中/待機** – ボタン押下後、外部ブラウザから戻ってきたコードをトークン交換中。プログレスインジケータを表示。
3. **認証済み** – トークン取得と必要なユーザー情報確認が済んだらテーブル一覧画面へ遷移。

### 機能

- ログイン開始（外部認可）
- 認可中の待機状態表示
- 認可成功後テーブル一覧画面へ遷移

## テーブル一覧画面

### 表示項目

表示項目は以下

- ヘッダー
- テーブル一覧リスト

#### ヘッダー

| 項目名　   | 表示形式 | 説明                             |
| ---------- | -------- | -------------------------------- |
| タイトル   | テキスト | タイトルを表示                   |
| 設定ボタン | ボタン   | 押下してログアウト画面に遷移する |

#### テーブル一覧リスト

| 項目名　   | 表示形式       | 説明                                                                                                                                                                                                         |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| テーブル行 | リストアイテム | テーブルを表し、テーブル名とチェックイン中の場合はチェックイン人数を表示する。押下時は状態に応じて遷移する（チェックアウト時: チェックイン画面へ、チェックイン中: 注文履歴画面へ）。 |
| 設定ボタン | ボタン         | 押下してログアウト画面に遷移する                                                                                                                                                                             |

### 機能
- テーブル一覧取得

## 注文画面

### 表示項目

表示項目は以下

- ヘッダー
- メニューリスト
- 注文リスト

#### ヘッダー

| 項目名　 | 表示形式 | 説明           |
| -------- | -------- | -------------- |
| タイトル | テキスト | タイトルを表示 |

#### メニューリスト

| 項目名　       | 表示形式       | 説明                                                                                                     |
| -------------- | -------------- | -------------------------------------------------------------------------------------------------------- |
| メニュー行     | リストアイテム | メニューを表し、メニュー名を表示する                                                                     |
| 点数           | 入力欄         | メニュー行上に表示。点数を1以上9以下で入力可能にする。                                                 |
| 点数増加ボタン | ボタン         | メニュー行上に表示。押下することで注文点数を1増加する。増加できない場合はグレーアウトにする。 |
| 点数減少ボタン | ボタン         | メニュー行上に表示。押下することで注文点数を1減少する。減少できない場合はグレーアウトにする。 |
| 追加ボタン     | ボタン         | メニュー行上に表示。<br>押下することで、メニューを注文リストに追加する                                   |

#### 注文リスト

| 項目名　   | 表示形式       | 説明                                                                                                                                     |
| ---------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 注文行     | リストアイテム | メニューリストで追加したメニューを表す。メニュー名と点数を表示し、スワイプ操作で削除可能にする。         |
| 注文ボタン | ボタン         | 押下することで注文処理を実行する。成功時はテーブル一覧画面に遷移し、エラー時はエラーダイアログを表示する。 |

### 機能

- メニュー一覧取得
- 注文
