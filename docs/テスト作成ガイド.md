# テスト作成ガイド

本ドキュメントは、ロジックの単体テストのみを対象とする。
UI / Widget テストは含めない。

# 1. 基本方針

- テスト対象は **domain / application / data のロジック**
- infrastructure（外部SDKの薄いラッパー）はテスト対象外
- UIはテスト対象外
- 外部通信・SDKはモック化する
- テストは lib 構造をミラーする
- モックは [mockito](https://pub.dev/packages/mockito) を利用する

# 2. テスト対象ごとの責務

## 2.1 Domain（Entity / VO）

### テストすること

- 不変条件
- バリデーション
- 値オブジェクトの等価性
- ビジネスルール

### テストしないこと

- 外部通信
- Repository実装

### 前提

- 純粋なロジックのみをテストする

## 2.2 UseCase（application層）

### テストすること

- Repositoryが正しく呼ばれているか
- ビジネスフローが正しいか
- 例外ハンドリング

### テストしないこと
- Repository実装
- DTO → Entity 変換など

### 前提

- RepositoryはMockにする
- 外部I/Oは行わない

---

## 2.3 RepositoryImpl（data層）

RepositoryImplは「外界とDomainの境界」である。
ApiClientをモック化し、publicメソッド経由でDTO → Domain変換を検証する。

### テストすること

- DTO → Entity の変換が正しいか
- Domain契約に沿った型・戻り値・挙動を守っているか

### テストしないこと

- HTTP通信の正しさ
- フレームワーク挙動（JSONパース等）

### 前提
- ApiClientはMockにする
- RepositoryImplのpublicメソッド経由でテストする（privateメソッドは直接テストしない）
- DTOは任意のダミーデータで用意する

## RepositoryImpl テストテンプレート

### 事前準備（モック生成）

```dart
import 'package:mockito/annotations.dart';
import 'package:mockito/mockito.dart';

import 'menu_repository_impl_test.mocks.dart';

@GenerateMocks([ApiClient])
void main() { ... }
```

### 成功パターン

```dart
test('正常系: MenuResponse が Menu ドメインに変換される', () async {
  final mockApiClient = MockApiClient();
  final repository = MenuRepositoryImpl(mockApiClient, contractId);

  when(mockApiClient.getStoreMenus(
    contractId: anyNamed('contractId'),
    storeId: anyNamed('storeId'),
  )).thenAnswer(
    (_) async => [
      MenuResponse(id: '1', name: 'ラーメン', ...),
    ],
  );

  final result = await repository.fetchMenuList(storeId: '1');

  expect(result.first.name, 'ラーメン');
});
```

#### 検証ポイント
- DTO → Entity が正しく変換されている
- nullを返していない

### 例外変換

```dart
test('DioException を AppException に変換する', () async {
  final mockApiClient = MockApiClient();
  final repository = MenuRepositoryImpl(mockApiClient, contractId);

  when(mockApiClient.getStoreMenus(
    contractId: anyNamed('contractId'),
    storeId: anyNamed('storeId'),
  )).thenThrow(DioException(...));

  expect(
    () async => repository.fetchMenuList(storeId: '1'),
    throwsA(isA<AppException>()),
  );
});
```

#### 検証ポイント
- Domain契約に沿って例外が変換されているか
