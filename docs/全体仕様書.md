# プロジェクト仕様書

プロジェクト全体の概要を記載する

## 機能要件

このアプリは、スマレジサービスを利用した注文管理アプリケーション。
飲食店で店員が利用することを想定し、以下の機能を提供する。

- テーブル管理
  - テーブル一覧取得
  - チェックイン
  - 会計
- 注文の作成と管理
  - メニュー一覧取得
  - 注文
  - 注文履歴確認
  - 注文取り消し
- 認証
  - ログイン
  - ログアウト

## 画面構成

以下の画面で構成する。詳細は画面仕様書.mdを参照。

- ログイン画面
- ログアウト画面
- テーブル一覧画面
- チェックイン画面
- 注文履歴画面
- 注文画面
  - メニュー一覧
  - 注文リスト
- 会計画面

## 外部API

本アプリはスマレジサービス・プラットフォームAPIを利用する。
各機能で利用を想定しているAPIは以下。

- アクセストークンAPIエンドポイント: `https://id.smaregi.dev`
- プラットフォームAPIエンドポイント: `https://api.smaregi.dev`

### 認証

| 機能       | 機能詳細             | リソース            |
| ---------- | -------------------- | ------------------- |
| ログイン   | ログイン（外部ブラウザで開く）             | /authorize          |
| ログイン   | アクセストークン取得 | /app/{契約ID}/token |
| ログイン |　ユーザー情報取得 | /userinfo |

### 注文・メニュー取得

| 機能             | 機能詳細                                         | リソース                                 |
| ---------------- | ------------------------------------------------ | ---------------------------------------- |
| テーブル一覧取得 | 店舗一覧取得　                                   | /stores                                  |
| テーブル一覧取得 | 店舗取得(テーブル一覧取得)　                     | /stores/{store_id}                       |
| チェックイン     | -                                                | /table_uses                              |
| メニュー一覧取得 | -　                                              | /stores/{store_id}/menus                 |
| 注文             | -　                                              | /table_uses/{table_use_id}/orders        |
| 注文履歴確認     | テーブル利用履歴取得（注文アイテムモデル取得）　 | /table_uses/{table_use_id}　             |
| 注文取り消し     | -　                                              | /table_uses/{table_use_id}/orders/cancel |

## 設計方針
- 状態管理 / DI は [riverpod](https://pub.dev/packages/riverpod)を利用する。[riverpod_generator](https://pub.dev/packages/riverpod_generator)を利用し、コードの記載を簡潔にする。
- ルーティングは[go_router](https://pub.dev/packages/go_router)を利用する
- フォルダ構成と依存関係は[フォルダ構成.md](フォルダ構成.md)を参照。
