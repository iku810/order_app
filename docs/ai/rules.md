# order_app

## アプリ概要

このアプリは、Flutter を使用して構築された注文管理アプリケーションです。
飲食店で店員が利用することを想定し、以下の機能を提供します。

- テーブル管理
- 注文の作成と管理

## 開発ガイドライン
- コード変更時の注意点
  - `analysis_options.yaml` に従う
  - パッケージの依存追加は最小限にする
  - docs/ フォルダ内の仕様書に参照し、プロジェクトの構成や方針に従う
    - docs/ フォルダ内の仕様書
      - [全体仕様書.md](/docs/全体仕様書.md)
      - [画面仕様書.md](/docs/画面仕様書.md)
      - [フォルダ構成.md](/docs/フォルダ構成.md)
      - [テスト作成ガイド](/docs/テスト作成ガイド.md)
- Widget作成
  - 画面全体を構成する Widget は `〇〇Page`として定義する
    - 画面内の小さな部品は `〇〇Widget` として定義する
  - ツリー構造を意識して、Widget を分割する
  - Widget作成時は、flutterが提供しているWidgetを優先して利用し、外部パッケージの利用は必要最低限にする
- コメント
  - コードの意図や理由を説明するためにコメントを活用する
  - コード自体が明確であれば、過剰なコメントは避ける
  - ドキュメントコメント（///）は、クラスや関数の説明に使用する
